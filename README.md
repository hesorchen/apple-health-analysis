# Apple Health Analysis

**把苹果健康导出变成一份可解释、可离线打开的交互 HTML 报告。**

本地处理，无 API Key，无云端上传，无健康评分。适合作为可加载的 Agent Skill，也可独立使用 Python 命令行。

> 这是消费级设备记录的观察性分析工具，不是医疗器械，不提供诊断或治疗建议。未标记异常不等于没有健康问题。

## 能做什么

- 直接读取 Apple Health 的 ZIP 或 XML，不必解压整个压缩包。
- 汇总睡眠与分期、心率、HRV、血氧、呼吸、活动、站立、训练、步态与移动能力、声音采样和身体测量；未支持类型保留目录计数。
- 生成**图表优先的单文件健康看板**：主题导航、统一日期与来源筛选、趋势图、悬浮／键盘读数；详细解读、方法和数据表按需展开。
- 每个来源都独立处理，手机长期历史与手表近期数据可切换查看，不互相覆盖或直接相加。
- 数据覆盖页区分扫描数、有效处理数、默认来源数与类型支持范围，不能把文件记录数包装成医学覆盖率。
- 单独展示每日最低血氧采样，避免被中位数掩盖；不推断低氧持续时间。
- 识别完全重复、覆盖缺口、旧身体资料和多个来源；不把手机与手表的步数直接相加。
- 支持明暗主题、窄屏与打印；无 CDN、外部字体、分析追踪或远程图表服务。

## 快速开始

需要 Python 3.10 及以上。运行时仅使用标准库。

```bash
python3 scripts/analyze.py /path/to/private/export.zip \
  --output-dir /path/to/private/report \
  --timezone Asia/Shanghai
```

随后用浏览器打开输出目录中的 `report.html`。`analysis.json` 保存可复核的聚合数据与方法信息。

**输出目录必须位于此项目之外。** HTML 和 JSON 都是敏感健康资料，不要上传公开仓库、公共图床或在线 HTML 预览站。原始文件不会被修改。

### 安装为 Skill

将完整目录安装到所用工具支持的 Skill 目录，例如：

```text
~/.agents/skills/apple-health-analysis/
├── SKILL.md
├── scripts/
└── references/
```

若工具只读取自己的 Skill 路径，可在其支持的入口建立指向本目录的链接。不要维护多个相互独立修改的源码副本。

示例请求：

> 分析这个苹果健康导出，在本地生成带图表的 HTML。先看数据覆盖与来源重复，再给最重要的观察和局限。不要上传原始数据。

### 不使用真实数据的演示

```bash
python3 scripts/make_demo.py /tmp/apple-health-demo/export.xml \
  --report /tmp/apple-health-demo/report.html
```

演示生成器只使用固定公式，**所有数值完全虚构**。它不读取用户目录，不从真实数据采样。缺口与一个低血氧样本是故意构造的，不代表某个人的健康情况。

## 可选参数

| 参数 | 作用 |
|---|---|
| `--timezone` | IANA 时区；不提供则保留记录原始 UTC 偏移 |
| `--config` | 私人 JSON 配置：按指标指定来源，附上本次实际核验的外部参考资料 |
| `--analyze-only` | 只生成 `analysis.json` |
| `--max-xml-mb` | 解压后 XML 的大小上限，默认 2000 MB |

来源配置示例，仅使用虚构名称：

```json
{
  "sources": {
    "steps": "Synthetic Watch"
  },
  "references": []
}
```

没有外部资料时仍可生成描述性报告，但不能将自动规则包装成已经核验的医疗建议。指南核验不属于离线 Python 运行器；由执行 Skill 的助手完成，并在报告中记录日期和核验范围。

## 重要口径

1．**来源不是越多越好。** 各来源独立聚合，默认每指标展示一个来源，通常优先 Watch，再比较覆盖天数；耳机声音优先覆盖天数，避免偶发手表采样压过长期手机记录。它是透明近似，不是对健康 App 私有合并算法的重建；多来源只切换，不自动拼接。

2．**没有记录不等于零。** 不填补未佩戴日；首尾日期可能不完整。观察日均值不是包含缺失日的完整日历均值。

3．**主睡眠不等于整日总睡眠。** 分期区间取并集，再按醒来日期选最长会话；清醒／卧床不算实睡，额外未分期睡眠另列。

4．**样本不是持续监测。** 血氧只代表采样点，不能用两个低点推算连续低氧。腕温不是核心体温，设备呼吸紊乱不是临床 AHI。

5．**历史不是现在。** 每指标有自己的覆盖范围；旧体重不当作当前体重，多年导出不等于多年生命体征监测。

详见 [方法与局限](references/methodology.md) 和 [Skill 工作流](SKILL.md)。

## 安全与开放源代码

- 默认不读取 GPS、CDA 或身份资料；报告使用通用来源别名，但健康趋势本身仍然敏感。
- 不联网发送数据；外部来源链接仅供读者主动打开。
- 不接受 XML 自定义实体；ZIP 不落地解压；拒绝多个不明确主 XML 和超限成员。
- XML 流式读取，但支持指标的记录与去重键保留在内存；超大导出仍需足够内存。
- 发布前只允许源码、文档、合成 fixture；真实报告、聚合 JSON、原始 ZIP／XML、截图和私人配置全部排除。
- `.gitignore` 只是辅助，不是保密措施；请检查 `git diff --cached`。
